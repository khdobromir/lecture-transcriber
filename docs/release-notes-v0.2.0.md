# Transcribe CLI v0.2.0

TXT теперь записывается во время распознавания, а отмена останавливает
whisper-cli и остальных работников. Для длинных записей добавлен режим
параллельной обработки частей.

## Изменения

- Расшифровка не выводится в терминал: остаются этапы, прогресс и ошибки;
  диагностика внешних инструментов сохраняется в журналы.
- `transcript.txt` дополняется по готовым сегментам. При дроблении общий файл
  сохраняет порядок записи; результаты последующих частей ожидают предыдущие.
- Ctrl+C, SIGTERM и SIGHUP завершают группы дочерних процессов, включая
  whisper-cli. Зависшие процессы принудительно останавливаются через две секунды.
- `--chunks` и `--jobs` задают число частей и параллельных работников.
  FFmpeg ищет паузы возле границ; TXT/SRT/VTT объединяются с общей шкалой времени.
- Число потоков по умолчанию учитывает доступные физические ядра и работников.
  Явный `--threads` задаёт число потоков каждого whisper-cli.
- `source.txt` создаётся до обработки и содержит статус, параметры и границы
  частей. После ошибки или отмены остаются частичный текст и рабочие файлы.
- Все тесты и подмены инструментов перенесены на C++23: 66 сценариев,
  Python для их запуска не нужен. CI проверяет GCC, Clang и Arch Linux.
- Actions Checkout обновлён до v7.0.1 с закреплённым commit SHA.

## Использование

По умолчанию запись обрабатывается целиком. Дробление включается явно:

```bash
transcribe --chunks 10 --jobs 2 --threads 3 "Лекция.mp4"
```

Одновременно работают два whisper-cli по три потока; каждая копия загружает
собственную модель. Десять частей не означают десять одновременных процессов.

Чтобы обновить существующую установку, получите исходники этого тега и повторите
`bash install.sh medium` обычным пользователем; вместо `medium` можно выбрать
`small` или `turbo`. Исправные модели проверяются и повторно не скачиваются.
После установки `transcribe --version` должен показать `transcribe 0.2.0`.
Полные зависимости и инструкции приведены в README.

## Совместимость и ограничения

Сохранены прежние параметры CLI и имена результатов. Изменилось автоматическое
число потоков и поведение терминального вывода. SRT/VTT появляются после полного
успеха; частичный TXT не подтверждает завершение — проверяйте статус `completed`
в `source.txt`.

Дробление увеличивает расход RAM; на коротких записях оно может замедлять работу.
Ускорение и качество на длинных русских лекциях ещё не измерены. Контекст между
частями не передаётся, поэтому речь возле границ следует проверить вручную.
Технические проверки и их границы описаны в
`docs/release-validation-v0.2.0.md` в исходниках выпуска.

Отмена охватывает потомков в управляемых группах процессов. SIGKILL самого
transcribe и потомки, самостоятельно покинувшие эти группы, не гарантируют очистку.
Загрузка конкретных видео VK текущими проверками не подтверждена.

Выпуск содержит исходники для Linux / Arch / Omarchy. Готовые бинарники и модели
не прикладываются. Лицензия собственного кода — MIT.
