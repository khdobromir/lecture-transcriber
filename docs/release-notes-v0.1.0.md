Первый релиз Transcribe CLI — консольной утилиты для транскрипции русской речи
на CPU в Arch Linux / Omarchy.

- Локальные видео/аудиофайлы и URL, поддерживаемые yt-dlp, включая VK Video.
- TXT, SRT, VTT и параметры источника в отдельном каталоге каждого запуска.
- whisper.cpp v1.9.4, модели small/medium/turbo и Silero VAD.
- Проверка SHA-256 моделей, докачка, безопасная передача аргументов без shell.
- Управление потоками, подсказки терминов, cookies и сохранение рабочего аудио.

Установка из исходников: клонируйте репозиторий и выполните `bash install.sh
medium` обычным пользователем после установки зависимостей из README.
Готовые бинарники и модели в релиз не входят. Лицензия собственного кода — MIT.

Загрузка конкретных видео VK текущими проверками не подтверждена и зависит
от сайта, yt-dlp, сети и авторизации. Проверки процессов и экспорта не являются
оценкой точности русских лекций или скорости на компьютере пользователя.
