## Изоляция и воспроизводимость

Ubuntu и Debian получены из официальных OCI-образов, слои проверены по SHA-256:

- Ubuntu 24.04 amd64 manifest:
  `sha256:f610ab94648195aa356059f5b41d6085c9d4d903c072430cdd1af7bdb646106b`.
- Debian 13-slim amd64 manifest:
  `sha256:7792b1f7702a86946cd518db72b6a407302c3e9bc1635634368b878189e8221c`.

Docker-сокет недоступен текущему пользователю. Проверки выполнены через
`bubblewrap` с user/PID namespaces: пакеты устанавливались только в rootfs
под `/tmp`, сборки и тесты запускались с UID 1000, системные деревья и снимок
проекта при проверках были доступны только для чтения. Основная система и
пользовательская установка transcribe не изменялись. Ограничение единственного
сопоставленного UID/GID вызывало предупреждения apt о владельце журналов;
настройка Ubuntu fontconfig завершилась после повторного запуска apt.

Real bootstrap использовал `scripts/ci-real-smoke.sh`, закреплённый Whisper
`927cfce34f31707e17f2bff35c349632fb9e2c3a` и medium/VAD из манифеста моделей.
Модели скачаны заново с проверкой SHA-256; пользовательский установщик не
запускался. Встроенный JFK обрезан до пяти секунд, язык — `ru`. Проверены
экспорт TXT/SRT/VTT, временные метки, статус и сохранность исходника.
Это проверка интеграции, а не оценка качества русской речи.

## Границы проверки

GitHub Actions, checkout/upload actions и еженедельное расписание в этой
сессии не запускались. Проверены локальные команды соответствующих job,
синтаксис workflow и закрепление actions по SHA. Расписание активируется
после появления workflow в default branch; настройки branch protection
не менялись.

LeakSanitizer не работает в текущем sandbox из-за ограничения ptrace.
Первый запуск с ним завершался диагностической ошибкой среды; повторные
проверки ASan/UBSan выполнены без проверки утечек, без изменения ptrace_scope
или других системных настроек. Проверка утечек памяти этим запуском не доказана.

Подавления clang-tidy адресные: буквальные скобки вместо временной метки,
сохранение первоначальной ошибки при best-effort flush, `N/A` от ffprobe
и явные позиционные пары/тройки в тестовых фикстурах. Группы проверок целиком
не отключались; автоматические исправления и `continue-on-error` не используются.
