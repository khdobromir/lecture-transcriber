# v0.5.0-beta.1

Первая бета нового интерфейса Material You / Material 3. Она предназначена для
проверки оформления и повседневных сценариев перед стабильной 0.5.0.
Стабильным выпуском остаётся v0.4.1; ручная приёмка Windows ещё не выполнена.

## Что изменилось

- Цвета интерфейса подбираются локально из обоев, выбранной картинки,
  готового пресета или собственного HEX-цвета. Светлая и тёмная палитры
  строятся Material Color Utilities по схеме Tonal Spot.
- Отдельные страницы расшифровки, истории, моделей и настроек, адаптивная
  навигация и общая панель прогресса. Переход между страницами сохраняет
  параметры запуска и состояние операции.
- Системная, светлая и тёмная темы, уменьшение анимаций. Русский и английский
  переключаются без перезапуска окна и активной задачи.
- Omarchy отслеживает текущие обои. Для Windows добавлен адаптер обоев
  основного монитора; его поведение на реальном рабочем столе ещё требует приёмки.
- Обработка изображений ограничена по размерам и памяти, выполняется в фоне;
  временная ошибка сохраняет последнюю рабочую палитру и допускает повтор.

## Установка и совместимость

Linux: скачайте `Transcribe-0.5.0-beta.1-linux-x86_64.AppImage`, разрешите запуск
и откройте файл. При недоступном FUSE добавьте `--appimage-extract-and-run`.
Локальная платформа проверки — Omarchy x86_64 / Wayland; требуется glibc 2.39+.
Для других Linux desktop выбор картинки или цвета доступен вручную.

Windows: распакуйте весь `Transcribe-0.5.0-beta.1-windows-x64.zip` и запустите
`bin/transcribe-gui.exe`. Автоматические сборка и smoke-проверки не заменяют
ручную приёмку Windows 11 x64. Отзывы по этому пакету нужны до стабильного выпуска.

Сверяйте SHA-256 каждого файла с digest в GitHub Releases. Модели в пакеты
не входят. Настройки, история, модели и результаты хранятся отдельно от приложения;
форматы TXT/SRT/VTT и CLI совместимы с предыдущим выпуском. Распознавание
остаётся русскоязычным и выполняется на CPU. Исходники и материалы сборки
публикуются рядом с пакетами.

## Проверки и ограничения

Фактические commit SHA, результаты CI, хеши пакетов и пропущенные сценарии
записываются в `release-validation.json` рядом с файлами выпуска.
[Область проверок](validation.md) описывает условия этой беты.
Предыдущий диагностический preview не является релизным пакетом.
Стабильная 0.5.0 требует завершения приёмки Windows и исправления найденных ошибок.
