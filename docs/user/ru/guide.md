# Руководство пользователя

[Быстрый старт](quick-start.md) · [Полное руководство на английском](../guide.md)
· [CLI](../cli.md)

В сборке текущих исходников переключатель сверху предлагает
**Автоматически / Automatic**, **Русский** и **English**. Автоматический режим
выбирает русский для русской системы, английский — для остальных. Выбор
сохраняется и применяется сразу, в том числе во время обработки записи или
операции с моделью; введённые данные и текущая задача сохраняются. Язык
распознавания и CLI остаётся русским. Системные диалоги могут сохранять язык ОС.
Опубликованный v0.4.1 содержит прежний GUI только на русском.

Приложение распознаёт русскую речь локально на CPU. За один запуск принимается
один файл или обычный HTTP(S) URL. Поддержка конкретного сайта зависит от yt-dlp
и прав доступа; прямые трансляции отклоняются. Подсказка с терминами помогает
контексту модели, но не гарантирует точность.

`small`, `medium`, `turbo` соответствуют квантованным моделям из
[manifest](../../../scripts/models.tsv). Выберите пресет на **Расшифровка**,
затем скачайте или импортируйте его на **Модели**; VAD импортируется отдельно.
Импорт проверяет точный SHA-256 выбранного пресета. Произвольный `.bin` нельзя
импортировать вместо него; пользовательский путь доступен в расширенных
настройках, но не получает гарантию проверки preset manager.
Повреждённая установленная модель сохраняется; действие восстановления сначала
создаёт резервную копию. VAD включён по умолчанию и требует собственного файла.

GUI выполняет одну задачу. В расширенных настройках `0` потоков/работников
означает автоматический выбор; CLI требует положительные числа при явном
указании. По умолчанию одна часть. Больше работников расходует больше памяти,
поскольку каждый загружает свою модель. Скорость и качество зависят от записи,
модели и компьютера; формулы, имена и термины нужно проверять.

TXT дополняется по порядку записи; SRT/VTT публикуются после успешного завершения.
Preview ограничен последними 512 КиБ; **Полный TXT** открывает весь файл.
100% прогресса ещё не означает сохранённый успех. Отмена сохраняет опубликованный
частичный текст и рабочие файлы, если они уже созданы. **Повторить задачу**
запускает новую задачу, а не продолжает с остановленного места.
Исходный локальный файл не удаляется. Принудительное завершение и выключение ОС
не гарантируют запись итогов.

История читает выбранные каталоги в фоне. Выбор старого результата не меняет
текущую задачу; для возврата используйте **Показать результат текущей задачи**.
Ctrl+O — файл, Ctrl+Enter — запуск, Ctrl+Q — закрытие, F5 — история.

| Данные | Linux | Windows |
|---|---|---|
| Модели | `~/.local/share/transcribe/models` | `%LOCALAPPDATA%\Transcribe\models` |
| Результаты по умолчанию | `~/Transcriptions` | `%USERPROFILE%\Transcriptions` |
| Медиакэш | абсолютный `$XDG_CACHE_HOME/transcribe/media` либо `~/.cache/transcribe/media` | `%LOCALAPPDATA%\Transcribe\cache\media` |

`TRANSCRIBE_HOME` меняет каталог данных/моделей, но не Linux-кэш или результаты.
`TRANSCRIBE_GUI_SETTINGS_FILE` позволяет выбрать отдельный INI настроек GUI.
Для обновления заменяйте полный AppImage/ZIP; модели, история и результаты
хранятся отдельно. Неполный пакет не использует случайные инструменты из PATH.
На Windows выбирайте короткие пути: входной файл до 240, родитель результатов
до 169 UTF-16 единиц; место резервируется для имён внешних инструментов.

Кэш загруженного медиа включён, лимит — 10 ГиБ. **Скачать заново** обновляет его;
отключение кэша запрещает чтение и запись. Для разрешённых закрытых источников
выберите либо Netscape cookies-файл, либо браузер/профиль, например `firefox`.
Cookies и prompt не сохраняются в настройках; повтор хранит параметры в памяти.
Системные конфигурации yt-dlp отключены. Каталоги плагинов отключены
начиная с 0.4.1; опубликованная v0.4.0 не изменяется. В текущей версии
пользовательские extractor plugins не поддерживаются. Не публикуйте cookies, приватные URL,
записи, transcripts и журналы без удаления личных данных.
