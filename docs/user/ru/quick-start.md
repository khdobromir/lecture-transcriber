# Быстрый старт

[English](../quick-start.md) · [Руководство пользователя](guide.md)

1. Скачайте приложение из [GitHub Releases](https://github.com/khdobromir/lecture-transcriber/releases/latest).
   Linux: x86_64, glibc 2.39+. Windows: Windows 11 x64. Архивы исходников и
   build-inputs для обычного запуска не нужны; модели скачиваются отдельно.
2. Сверьте SHA-256 с digest этого файла на странице GitHub Release
   (раскройте сведения о файле). Начиная с 0.4.1 отдельные `.sha256`/`SHA256SUMS`
   не публикуются; старые файлы v0.4.0 сохранены. Linux — `sha256sum ИМЯ.AppImage`, PowerShell —
   `Get-FileHash -Algorithm SHA256 -LiteralPath '.\ИМЯ.zip'`.
3. Linux: `chmod +x ИМЯ.AppImage`, затем `./ИМЯ.AppImage`. При отсутствии FUSE:
   `./ИМЯ.AppImage --appimage-extract-and-run`; понадобится место для временной
   распаковки. Windows: распакуйте **весь ZIP** и запустите
   `bin\transcribe-gui.exe`. Устанавливать Qt, Python и FFmpeg не нужно.
4. На вкладке **Расшифровка** выберите `small` для первого теста. На вкладке
   **Модели** нажмите **Скачать small и VAD** и дождитесь успешной проверки.
   Для первого запуска без сети заранее получите точные файлы из
   [models.tsv](../../../scripts/models.tsv) и используйте **Импорт small…** и
   **Импорт VAD…**. Предварительно выберите соответствующую модель.
5. Вернитесь на **Расшифровка**, выберите локальную запись, каталог результатов
   и нажмите **Начать расшифровку**. Оставьте одну часть и автоматические потоки.
   `medium` — стандартная модель нового GUI; она может работать дольше.
6. Дождитесь подтверждённого завершения. В **Каталог** находятся
   `transcripts/transcript.txt`, `.srt`, `.vtt`, `logs/` и `result.json`.

После установки моделей локальная запись обрабатывается без сети. URL и загрузка
моделей требуют интернет. **Отменить** сохраняет уже опубликованный частичный
текст; повтор запускает распознавание заново. При ошибке см.
[устранение неполадок](../../troubleshooting.md) и [руководство](guide.md).
