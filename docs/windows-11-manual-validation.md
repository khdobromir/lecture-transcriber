# Ручная проверка Windows 11

Проверяется portable ZIP на Windows 11 x64 без установки Qt, Visual Studio,
Python, Git, FFmpeg или Whisper. Модели загружаются самим приложением отдельно.
Наличие среды и успешный CI не заменяют результаты этой проверки.

## Подготовка

1. Записать Windows build из `winver`, объём RAM и масштаб экрана.
2. Получить ZIP кандидата и его `.sha256`. В GitHub artifact может находиться
   также `.build-inputs.tar.gz`: это материалы исходников, для запуска они
   не нужны. Если скачан внешний artifact ZIP, сначала распаковать его,
   затем использовать внутренний `Transcribe-*.zip`.
3. В PowerShell сверить SHA-256 внутреннего ZIP с предоставленной суммой:

   ```powershell
   Get-FileHash -Algorithm SHA256 -LiteralPath '.\Transcribe-....zip'
   ```

4. Распаковать весь ZIP в каталог с кириллицей и пробелами, например
   `C:\Users\<пользователь>\Desktop\Проверка Transcribe`. Сохранять структуру
   пакета: приложение, CLI и tools должны оставаться на своих местах.
5. Записать `source` и `application_version` из `package-manifest.json`.
   Запускать `bin\transcribe-gui.exe` из распакованного пакета.

## Сценарии

| Проверка | Ожидаемый результат |
| --- | --- |
| Первый запуск | Окно открывается без установки дополнительных runtime/SDK; нет ошибки отсутствующей DLL |
| Диалоги и DPI | Выбор файлов работает; текст и кнопки доступны при пользовательском масштабе и минимальном размере окна |
| Клавиатура | Tab/Shift+Tab перемещают фокус; доступные кнопки активируются клавиатурой |
| Скачать модель | На вкладке «Расшифровка» выбрать `small`, на вкладке «Модели» нажать «Скачать small и VAD»; загрузка завершается без ошибки |
| Импорт модели | Если есть заранее проверенный файл модели/VAD, импорт через соответствующий диалог завершается успешно |
| Локальное распознавание | Выбрать собственную запись речи; оставить VAD включённым; во время работы появляется preview, затем успешный результат |
| Экспорт | TXT/SRT/VTT созданы и читаются; копирование текста в Блокнот и открытие папки результатов работают |
| Отмена | На достаточно длинной записи отменить задачу; GUI остаётся доступным; уже опубликованный partial text сохраняется, если он успел появиться |
| Повтор | «Повторить задачу» после отмены запускает новую задачу и завершает её успешно |
| Закрытие во время задачи | Закрыть приложение во время распознавания; после завершения закрытия в Диспетчере задач не остаются его `transcribe.exe`, `whisper-cli.exe`, `ffmpeg.exe` |
| Перезапуск | После повторного запуска история сохранена; прежний завершённый результат и его exports открываются |
| Default medium + VAD | Скачать `medium` и VAD; реальная запись распознаётся с настройками по умолчанию |
| Turbo / chunks | Отдельно проверить `turbo` и один/несколько chunks; записать выбранные значения и результат |

Для проверки отмены можно использовать ту же длинную локальную запись, которая
нужна для приёмки лекции длительностью 10–15 минут. Не отправлять личную запись,
полный transcript, cookies или приватные URL в публичные issues/CI artifacts.
Отсутствие установленного приложения для открытия SRT/VTT следует записать
отдельно от целостности самих export files; их можно открыть в Блокноте.

## Результат

Сохранить локально краткий отчёт:

```text
Windows build:
RAM / DPI scale:
Package filename / SHA-256:
Manifest source / version:
Models / VAD / chunks:
Passed scenarios:
Failed scenarios and reproduction steps:
Not checked:
```

В ответе достаточно перечислить успешные пункты и точный текст ошибок.
Предварительная проверка старого кандидата полезна для поиска дефектов; итоговый
допуск должен относиться к окончательному ZIP с записанной контрольной суммой.
