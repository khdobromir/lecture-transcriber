# Transcribe CLI v0.3.0

Выпуск добавляет хранение результатов по названию и дате, кэш скачанного
медиа и прогресс с примерным оставшимся временем. Изменились пути результатов;
скриптам, читающим файлы версии 0.2.1, потребуется обновление.

## Новые возможности

- По умолчанию результаты находятся в `$HOME/Transcriptions`.
  Каждый запуск получает каталог `Название_YYYY-MM-DD_HH-MM-SS`:
  TXT/SRT/VTT лежат в `transcripts/`, диагностика — в `logs/`,
  сведения об источнике — в `source.txt`. Названия очищаются от разделителей
  путей и управляющих символов; совпавшие имена не перезаписываются.
- Терминальный прогресс обновляет одну строку с ETA, взвешенным по длительности
  частей. В перенаправленном выводе и `TERM=dumb` используются обычные строки.
  `--no-progress` отключает промежуточный прогресс.
- Кэш медиа по умолчанию хранится в `$XDG_CACHE_HOME/transcribe/media`
  или `$HOME/.cache/transcribe/media`; лимит — 10 ГиБ с LRU.
  Повторный запуск по тому же URL может получить медиа без сети;
  другой URL сопоставляется по идентификатору источника после запроса метаданных.
  Добавлены `--cache-dir`, `--cache-limit-gib`, `--refresh-cache`, `--no-cache`.
  Параллельные загрузки защищены блокировкой, публикация следует за проверкой
  аудио. Содержимое cookies в кэш не копируется, live-потоки не сохраняются.

## Исправления и проверки

- Предварительная проверка отклоняет каталог вместо исполняемого whisper-cli
  до создания результатов и конвертации.
- SRT/VTT проверяются относительно длительности каждой части; превышение
  до 10 мс обрезается как округление, большее завершает обработку ошибкой,
  сохраняя рабочее аудио и частичный текст.
- CI повторяет сценарии кэша и параллельных загрузок двадцать раз;
  сохраняются проверки SIGINT, падения Whisper, объединения частей,
  установки и статического анализа на Ubuntu, Debian и Arch.
- На Ryzen 5 7430U с medium-q5_0 подтверждён полный запуск на общедоступной
  лекции 93:30: весь запуск — 68:55, пик PSS — 1.98 ГиБ.
  Повторное чтение кэша проверено без сети. Ссылка, название и текст источника
  не публикуются.

## Переход с 0.2.1

Получите исходники тега `v0.3.0` и обновите CLI согласно README.
`transcribe --version` должен показать `transcribe 0.3.0`.
Модели и движок не изменились; исправные модели повторно не скачиваются.

`--out` теперь задаёт родительский каталог результатов; значение по умолчанию
перенесено из текущей директории в `$HOME/Transcriptions`. Для прежнего
родительского каталога явно передайте `--out ./transcripts`, но учитывайте новое
имя каталога запуска и вложенные `transcripts/transcript.*`, `logs/*.log`.
Старые результаты автоматически не перемещаются. Если кэш не нужен, используйте
`--no-cache`. Кэш недоступен — программа предупреждает и скачивает обычным способом.

## Ограничения

ETA приблизительный: между обновлениями процента оценка может расти.
На одном длинном запуске средняя абсолютная ошибка составила 3.49 мин,
95-й процентиль — 11.25 мин; это не обещание точности для других записей.
Кэш сохраняет снимок медиа: для изменившегося содержимого используйте
`--refresh-cache`. Кэш авторизованных загрузок остаётся приватными локальными
данными; смена аккаунта в том же профиле браузера не гарантирует новый ключ кэша.

Выпуск содержит исходники, без бинарников и моделей. Пользовательская установка
рассчитана на Arch/Omarchy; язык распознавания — `ru`. Один успешный источник
не гарантирует доступность других видео или качество распознавания.
Качество слов возле границ частей не измерялось. SIGKILL самого transcribe
и потомки, покинувшие управляемые группы, остаются ограничениями отмены.
TUI/GUI оценены в документации; переход на Go и новый интерфейс не реализованы.
