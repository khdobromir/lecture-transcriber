Версия CMake и CLI — `0.2.0`. Основа выпуска — `dev` после слияния
`origin/master` (`fce18f9`): сохранены новые C++-тесты и Checkout v7.0.1.
Для проверки использована отдельная чистая копия исходников без `.git`,
прежних сборок, локальных моделей, записей и личных результатов.

FFmpeg настоящий. Реальный smoke выполнен отдельно после сборок и CTest.
Он использовал уже установленные движок и модели; в исходники выпуска
они не включаются.

## Удалённый CI и публикация

GitHub Actions проверяет Ubuntu GCC, Ubuntu Clang и Arch Linux. Актуальный
результат для подготовленного коммита и PR доступен в
[CI](https://github.com/khdobromir/lecture-transcriber/actions/workflows/ci.yml).
После слияния PR отдельно проверяется CI итогового коммита `master`,
на который затем ставится тег; порядок описан в [инструкции](releasing.md).

Этот документ фиксирует локальные результаты подготовки, а не заранее
объявляет результат удалённого CI или публикацию тега.

## Границы проверки

Английский JFK с языком `ru` подтверждает запуск реального движка и экспорт,
но не точность русских лекций. Длинная русская запись не предоставлена:
ускорение дроблением и качество речи возле границ на ней не измерены.
Предыдущий короткий эксперимент с 10 частями описан в
[отчёте разработки](dev-validation.md); его времена не являются рекомендацией
по выбору числа потоков и работников.

Реальная загрузка VK и cookies не проверялась. SIGKILL самого transcribe
и потомки, самостоятельно покинувшие управляемые группы, остаются
документированными ограничениями отмены.
