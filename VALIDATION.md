# Проверка проекта — 1 октября 2026

Среда проверки: Linux x86_64, GCC 13.3, CMake 4.4.3, настоящий FFmpeg.
Проверка выполнена в среде подготовки проекта, а не на ноутбуке пользователя.

- `g++ -std=c++23 -O2 -Wall -Wextra -Wpedantic -Werror src/main.cpp`:
  сборка без предупреждений.
- CMake-сборка управляющей программы: успешно.
- whisper.cpp v1.9.4, commit `927cfce34f31707e17f2bff35c349632fb9e2c3a`:
  успешно собран `whisper-cli` с CPU backend и статическими whisper/ggml,
  `GGML_CUDA=OFF`, `GGML_VULKAN=OFF`, `GGML_BLAS=OFF`.
- `bash -n install.sh scripts/download-model.sh`: успешно.
- `python tests/test_pipeline.py`: **8 из 8 интеграционных тестов прошли**.
  FFmpeg настоящий; сеть и распознавание в этих тестах заменены управляемыми
  процессами. Проверены пути с русскими буквами, пробелами и спецсимволами,
  URL и cookies, экспорт, сохранность локального исходника, отдельные каталоги,
  ошибки загрузки/движка/FFmpeg, параметры и отключение VAD.
- Дополнительно выполнен реальный процесс: yt-dlp 2026.08.19 скачал WAV с
  локального HTTP-сервера, FFmpeg подготовил звук, whisper.cpp с моделью `tiny`
  и Silero VAD 6.2.0 создал TXT/SRT/VTT. Рабочие файлы удалены после успеха.
- `scripts/download-model.sh small`: реальная загрузка `small-q5_1` завершена,
  `.part` переименован в готовый файл. Отдельно проверен запуск распознавания
  с этой квантованной моделью.

Для проверки запуска использован пятисекундный фрагмент встроенного примера
`samples/jfk.wav`. Это техническая проверка процессов и экспорта, не оценка
точности распознавания русских университетских лекций и не замер скорости
на ноутбуке пользователя. Программа явно задаёт язык `ru`.

Установка пакетов через pacman и полный пользовательский запуск `install.sh`
в Omarchy здесь не выполнялись. Команды сборки и загрузка моделей проверены
отдельно; Bash-синтаксис установщика проверен. Модель medium по умолчанию
не использовалась для проверки качества/скорости.
