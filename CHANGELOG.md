# Изменения

## 0.1.0 — подготовлен к выпуску

Первый релиз исходников; дата публикации будет указана при создании релиза.

- Название Transcribe CLI, команда `transcribe`, переменные `TRANSCRIBE_HOME`
  и `TRANSCRIBE_BUILD_JOBS`, каталог данных `~/.local/share/transcribe`.
- Расшифровка русских локальных записей и доступных URL через whisper.cpp на CPU.
- TXT, SRT, VTT и сведения об источнике в отдельном каталоге каждого запуска.
- Модели small/medium/turbo, Silero VAD, подсказки терминов и cookies для yt-dlp.
- Установка для Arch/Omarchy с закреплённым whisper.cpp v1.9.4.
- Модели закреплены по ревизиям и SHA-256; поддержаны докачка и повторная установка.
- Временные сборки, блокировка одновременных установок, сохранение предыдущих
  исполняемых файлов при ошибках сборки или загрузки.
- `--version`, CTest, проверки GCC/Clang и Arch в GitHub Actions.
- MIT, публичная документация и инструкции для участников.

Ограничения: язык распознавания `ru`, Linux/POSIX, установка из исходников.
Загрузка конкретных видео VK не подтверждена текущими проверками.
Точность русских лекций и скорость на компьютере пользователя не измерялись.
