# Изменения

## Unreleased

- Portable GUI integration запускает настоящий CLI с mock внешними tools;
  проверяет live preview, экспорты, URL/cache, cancel/tree cleanup и retry.
- CI проверяет GUI также с Qt 6.11.2 на Linux, запускает ASan/UBSan и включает
  GUI compilation database в static analysis; диагностики сохраняются в artifacts.

- GUI разделяет текущую задачу и выбранный результат; ошибки preflight не меняют
  историю. Добавлены повтор задачи, отдельные каталоги/журналы и контексты ошибок.
- Состояния задачи/модели имеют guards; workers отменяются кооперативно,
  устаревшие callback отбрасываются, закрытие ждёт операции асинхронно.
- Публикация модели выполняется в worker под installation lock. Повреждённую
  модель можно явно восстановить после сохранения резервной копии.

- GUI и CLI используют общий типизированный валидатор protocol v1; GUI
  проверяет порядок событий, пути, прогресс и итог, читает поток порциями.
- Linux supervisor завершает и собирает управляемые дочерние группы даже
  после принудительной остановки CLI; исходный exit code инструмента сохранён.
- Загрузка моделей восстанавливается после HTTP 416 одним сбросом непригодного
  .part; диапазоны проверяются полностью, временные файлы привязаны к SHA-256.
- История выбирает последние 2000 результатов после поиска по всем roots,
  сохраняет время недоступных записей и вытесняет старые пути из QSettings.

- Собственные читатели TXT/result.json разрешают атомарную замену на Windows;
  временные sharing/locking ошибки публикации имеют ограниченные отменяемые повторы.
- Нарезка 1–256 частей использует filter graph в файле и ограниченные группы
  выходов; Windows-предел проверяется по итоговой quoted UTF-16 команде с NUL.

- Windows 11 x64 backend: Unicode argv/пути, Job Objects, межпроцессные блокировки,
  приватные ACL и атомарная публикация результатов; Linux API вынесен в адаптеры.
- Qt Quick GUI для Linux/Windows: одна задача, прогресс/ETA, частичный текст,
  отмена и подтверждение закрытия, история и загрузка/импорт моделей с SHA-256.
- Общее ядро pipeline, JSONL `--machine` и версионированный `result.json`.
- Windows ZIP builder с закреплёнными инструментами, Unicode-патчем whisper.cpp,
  Qt deployment, лицензиями, манифестом и package smoke; новые CI jobs и тесты.

## 0.3.0 — 2026-10-03

- Каталог результата называется по названию видео и локальной дате/времени
  запуска; по умолчанию результаты находятся в `$HOME/Transcriptions`.
  Расшифровки перенесены в `transcripts/`, вся диагностика — в `logs/`.
- В терминале прогресс обновляется в одной строке с примерным ETA;
  перенаправленный вывод остаётся текстовым, `--no-progress` отключает прогресс.
- Кэш скачанного аудио с повторным использованием URL без сети, сопоставлением
  идентификаторов видео, атомарной публикацией и блокировкой параллельных загрузок.
  Лимит по умолчанию — 10 ГиБ с LRU; добавлены `--cache-dir`,
  `--cache-limit-gib`, `--refresh-cache` и `--no-cache`.
- Тесты каталогов результатов, ETA, терминального отображения и кэша;
  архитектурная оценка TUI/GUI без изменения текущего C++ backend.
- Каталог вместо whisper-cli отклоняется при предварительной проверке до
  создания результатов и конвертации аудио.
- Временные метки SRT/VTT проверяются относительно длительности каждой части.
  Выход до 10 мс из-за округления обрезается до границы; большее превышение
  завершает обработку ошибкой и сохраняет частичный текст и рабочее аудио.
- Полный запуск на общедоступной лекции длительностью 93:30 и повторное
  чтение аудио из кэша без сети подтверждены; опубликованы обезличенные
  измерения времени, ресурсов и погрешности ETA.

## 0.2.1 — 2026-10-02

- Отдельные unit-тесты CLI, предварительной валидации, WAV и объединения экспортов;
  проверки падения Whisper после частичного текста и многопроцессной отмены SIGINT.
- CI дополнен Debian 13, clang-tidy и cppcheck; реальный Whisper smoke запускается
  вручную и еженедельно отдельно от обязательных проверок PR.
- `smoke_real --artifacts НОВЫЙ-КАТАЛОГ` сохраняет технические результаты и
  диагностику для проверки CI, в том числе после ошибки.
- Успех фиксируется до удаления рабочего аудио: сигналы во время последующей
  очистки не меняют статус `completed` и код `0`; ошибка очистки даёт предупреждение.
- Закрытие pipe при выводе финального сообщения возвращает `141` и сохраняет
  рабочее аудио со статусом `interrupted`.

## 0.2.0

- Расшифровка сохраняется в TXT по готовым сегментам и не выводится в терминал;
  этапы и общий прогресс остаются видимыми, диагностика записывается в журналы.
- Ctrl+C, SIGTERM и SIGHUP останавливают все группы работников с потомками;
  через две секунды зависшие процессы завершаются принудительно.
- `--chunks` и `--jobs`: очередь параллельного распознавания частей, границы
  возле пауз, объединение TXT/SRT/VTT с общей шкалой времени.
- Автоматический выбор потоков по физическим ядрам и числу работников;
  `--threads` задаёт число потоков каждого whisper-cli.
- Ранний `source.txt` со статусом и границами; при ошибке сохраняются
  частичный текст, результаты отдельных частей и рабочее аудио.
- Тесты и подмены инструментов перенесены на C++23; Python для тестов не нужен.
- CI запускается также для `dev`.
- GitHub Actions Checkout обновлён до v7.0.1 с закреплением по commit SHA.

## 0.1.0 — 2026-10-01

- Название Transcribe CLI, команда `transcribe`, переменные `TRANSCRIBE_HOME`
  и `TRANSCRIBE_BUILD_JOBS`, каталог данных `~/.local/share/transcribe`.
- Расшифровка русских локальных записей и доступных URL через whisper.cpp на CPU.
- TXT, SRT, VTT и сведения об источнике в отдельном каталоге каждого запуска.
- Модели small/medium/turbo, Silero VAD, подсказки терминов и cookies для yt-dlp.
- Установка для Arch/Omarchy с закреплённым whisper.cpp v1.9.4.
- Модели закреплены по ревизиям и SHA-256; поддержаны докачка и повторная установка.
- Временные сборки, блокировка одновременных установок, сохранение предыдущих
  исполняемых файлов при ошибках сборки или загрузки.
- `--version`, CTest, проверки GCC/Clang и Arch в GitHub Actions.
- MIT, публичная документация и инструкции для участников.

Ограничения: язык распознавания `ru`, Linux/POSIX, установка из исходников.
Загрузка одной общедоступной лекции VK и скорость на Ryzen 5 7430U измерены
в [отчёте](docs/lecture-validation-2026-10-03.md); доступность других видео,
точность распознавания и качество возле границ частей этим не подтверждаются.
