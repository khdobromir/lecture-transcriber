# Security reporting

For a suspected vulnerability, use **Report a vulnerability** on the repository's
[Security page](https://github.com/khdobromir/lecture-transcriber/security).
GitHub private vulnerability reporting is enabled. Please do not disclose an
unfixed vulnerability or sensitive reproduction data in a public issue.

Include the affected version/commit, OS, installation route, impact and minimal
reproduction. Use harmless fixtures and redacted diagnostics. Do not send account
cookies/tokens, private URLs, recordings, full transcripts or model weights.
English and Russian reports are welcome.

This individually maintained project reviews reports on a best-effort basis;
there is no guaranteed response time or long-term support branch. Reproduce on
current code/latest release when possible; an older build may need an upgrade.
Ordinary bugs and feature requests belong in public issues with private data
removed. Third-party tool/model vulnerabilities may also require upstream fixes
and a new complete package; see [dependency inventory](THIRD_PARTY.md).
