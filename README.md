# VK Lecture: русские лекции → TXT, SRT, VTT

Готовая консольная утилита на C++23 для **Omarchy / Arch Linux**, работающая на CPU.
Принимает URL VK Video либо локальный видео/аудиофайл. Для каждой лекции создаёт
отдельный каталог, скачивает доступный аудиопоток, готовит WAV и запускает
распознавание русского языка через whisper.cpp. Интернет нужен для установки
и скачивания видео; уже скачанные файлы распознаются локально.

## 1. Из чего состоит решение

| Часть | Назначение |
|---|---|
| `src/main.cpp` | Программа на C++23: параметры, загрузка, конвертация, запуск распознавания, результаты и ошибки |
| `whisper.cpp` / `whisper-cli` | Движок распознавания на C/C++, собранный для CPU |
| Многоязычная модель Whisper | Распознавание русской речи; по умолчанию `medium-q5_0` |
| Silero VAD | Определение участков речи; по умолчанию включено |
| `yt-dlp` | Получение видео/аудио с VK Video |
| FFmpeg | Подготовка WAV: моно, 16 000 Гц, PCM 16 бит |
| `install.sh` | Сборка движка и программы, установка команды, скачивание моделей |
| `scripts/download-model.sh` | Загрузка дополнительной модели |

Программа использует стандартную библиотеку C++ и POSIX API Linux. Она вызывает
готовый `whisper-cli` как отдельный процесс, а не подключает `whisper.h` напрямую.
Сами нейросетевые вычисления выполняет C++-движок. Это позволяет использовать
его готовый экспорт субтитров и VAD. `system()` и shell для запуска команд
не используются: аргументы передаются через `posix_spawnp`.

`yt-dlp` — программа на Python, которую устанавливает pacman вместе с нужными
зависимостями. Отдельный venv, faster-whisper, PyTorch и CUDA здесь не нужны.

## 2. Установка системных зависимостей

В терминале Omarchy:

```bash
sudo pacman -S --needed base-devel cmake git curl ffmpeg yt-dlp unzip
```

`base-devel` содержит компилятор GCC, Make и инструменты сборки. CMake управляет
сборкой; Git получает исходники; curl скачивает модели. OpenBLAS не требуется:
установщик собирает обычный CPU backend whisper.cpp. Библиотеки whisper/ggml
собираются из исходников со статической линковкой в `whisper-cli`.

Если pacman сообщает 404 при скачивании пакетов, обнови систему целиком через
`sudo pacman -Syu`, затем повтори команду. Не используй отдельный `pacman -Sy`.

## 3. Распаковка проекта

Скачай `vklecture-cpp.zip` из ответа и сохрани в `~/Downloads`. Затем:

```bash
mkdir -p ~/Applications
unzip ~/Downloads/vklecture-cpp.zip -d ~/Applications
cd ~/Applications/vklecture-cpp
```

Если архив лежит в другом каталоге, подставь его путь вместо `~/Downloads`.

## 4. Сборка и загрузка модели

Для начала используй `medium`:

```bash
bash install.sh medium
```

Запускай **без sudo**. Установщик:

1. Проверяет наличие системных инструментов.
2. Загружает исходники whisper.cpp **v1.9.4**, commit
   `927cfce34f31707e17f2bff35c349632fb9e2c3a`.
3. Собирает `whisper-cli` для CPU без CUDA/Vulkan, с оптимизацией Release.
4. Компилирует C++-утилиту и устанавливает `~/.local/bin/vklecture`.
5. Скачивает `medium-q5_0` и небольшую модель Silero VAD с Hugging Face.
6. Сохраняет выбранную модель как модель по умолчанию.

Сборка идёт в два параллельных задания, чтобы уменьшить нагрузку на ноутбук.
Для более мощного CPU можно задать, например:

```bash
VKLECTURE_BUILD_JOBS=4 bash install.sh medium
```

Если сразу важнее скорость, используй `bash install.sh small`.
Модели скачиваются с окончанием `.part`; файл становится доступен программе
только после успешной загрузки. Повторный запуск позволяет докачать `.part`.
Готовые модели повторно не скачиваются. Установщик не проверяет хеши моделей.

## 5. Добавление команды в PATH

Для текущего терминала:

```bash
export PATH="$HOME/.local/bin:$PATH"
vklecture --help
```

Чтобы команда была доступна в новых терминалах, добавь эту же строку
`export PATH="$HOME/.local/bin:$PATH"` в `~/.bashrc`, если используешь Bash,
либо в `~/.zshrc`, если используешь Zsh. Существующий PATH при этом сохраняется.
Для Fish выполни `fish_add_path ~/.local/bin`.

Команду также можно запускать без изменения PATH:

```bash
~/.local/bin/vklecture --help
```

## 6. Расшифровка твоей лекции из VK

```bash
vklecture "https://vkvideo.ru/video-213618393_456239673?list=ln-fXSQq4q4CtBecy69iY"
```

Вставляй обычный URL в кавычках. Разметка `[URL](URL)` из Markdown не подходит.
Параметр `--no-playlist` заставляет утилиту обработать одно видео, даже если
в ссылке есть параметр `list`.

В текущем каталоге появится `transcripts/lecture-ДАТА-ВРЕМЯ-суффикс/`:

| Файл | Содержимое |
|---|---|
| `transcript.txt` | Обычный текст, без временных меток |
| `transcript.srt` | Субтитры с временными метками |
| `transcript.vtt` | Субтитры WebVTT |
| `source.txt` | Ссылка/путь источника, модель и параметры |

Утилита печатает полный путь к результату. Повторные запуски создают новые
каталоги и не перезаписывают предыдущие расшифровки.

По умолчанию используется `bestaudio/best`: предпочтение отдаётся отдельному
аудиопотоку. Если VK его не предоставляет, скачивается видео со звуком —
это может потребовать заметно больше места. После успешного распознавания
временные файлы удаляются; при ошибке остаются для диагностики.

## 7. Локальные файлы и выбор каталога

Видео:

```bash
vklecture "$HOME/Downloads/Лекция 1.mp4"
```

Аудио, уже скачанное через yt-dlp:

```bash
vklecture "$HOME/Downloads/lecture.opus"
```

Результаты в отдельной папке и сохранение промежуточного аудио:

```bash
vklecture --out "$HOME/Documents/Лекции" --keep-audio \
  "https://vkvideo.ru/video-213618393_456239673"
```

`--out` задаёт родительский каталог. Внутри него создаётся отдельная папка
лекции. `--keep-audio` сохраняет подпапку `audio` с WAV и загруженным исходником.
Локальный исходный файл программа никогда не удаляет.

## 8. Как ускорить распознавание

| Параметр | Модель | Для чего |
|---|---|---|
| `small` | `small-q5_1` | Более лёгкая модель; удобна для первой проверки скорости |
| `medium` | `medium-q5_0` | Стартовый вариант для лекций с русскими терминами |
| `turbo` | `large-v3-turbo-q5_0` | Дополнительный вариант для сравнения; требует больше памяти, чем small |

Качество и скорость зависят от CPU, записи и темы лекции. Квантизация уменьшает
размер модели и требования к памяти; ускорение зависит от железа. Точного
времени для твоего ноутбука заранее обещать нельзя, `medium` на слабом CPU
может работать медленнее длительности самой лекции.

Для medium заложи несколько ГБ свободной оперативной памяти; WAV занимает
примерно 110 МиБ на час записи, дополнительно нужно место для модели и
скачанного файла. whisper-cli загружает аудио в память, поэтому очень длинные
лекции потребуют больше RAM.

Скачать small и использовать её, сохранив medium:

```bash
cd ~/Applications/vklecture-cpp
bash scripts/download-model.sh small
vklecture --model small --threads 4 "$HOME/Downloads/Лекция 1.mp4"
```

Дополнительная turbo:

```bash
bash scripts/download-model.sh turbo
vklecture --model turbo "$HOME/Downloads/Лекция 1.mp4"
```

Чтобы сделать другую модель постоянной, повтори `bash install.sh small`.
Можно передать путь к собственной совместимой GGML-модели:

```bash
vklecture --model "$HOME/models/ggml-medium.bin" "Лекция 1.mp4"
```

Модели с `.en` в названии предназначены для английского и для русских лекций
не подходят. Модель задаётся файлом GGML `.bin`, а не файлами faster-whisper.

Потоки по умолчанию: не более четырёх и не больше числа доступных логических
CPU. Попробуй `--threads 2`, `4` и `6` на одном фрагменте, если хочешь выбрать
наиболее быстрый вариант. Увеличение числа потоков не гарантирует ускорения.

## 9. Пробный фрагмент перед полной лекцией

Необязательно ждать обработку нескольких часов. Из локального файла выдели
первые пять минут и сравни качество/скорость:

```bash
ffmpeg -nostdin -i "Лекция 1.mp4" -t 300 -vn -ar 16000 -ac 1 \
  -c:a pcm_s16le "test-5min.wav"
vklecture --model small "test-5min.wav"
vklecture --model medium "test-5min.wav"
```

## 10. Термины и участки тишины

Для математической лекции можно дать краткую подсказку:

```bash
vklecture --prompt "Тензор, ковариантный, контравариантный, базис, симметризация." \
  "Лекция 1.mp4"
```

Подсказка может помочь с терминологией, но не гарантирует правильного написания.
Не передавай в неё длинный предполагаемый текст лекции. Распознавание речи
не извлекает формулы с доски или слайдов; формулы и фамилии нужно проверять.

VAD включён по умолчанию: участки без речи не передаются Whisper. Если тихие
реплики пропали, сравни результат с отключённым VAD:

```bash
vklecture --no-vad "Лекция 1.mp4"
```

## 11. Если VK требует входа

Сначала проверь, открывается ли видео у тебя в браузере. Для видео, доступного
твоему аккаунту, передай cookies соответствующего браузера:

```bash
vklecture --cookies-from-browser firefox "https://vkvideo.ru/video..."
```

Или для Chromium:

```bash
vklecture --cookies-from-browser chromium "https://vkvideo.ru/video..."
```

Можно указать профиль Chromium в формате, который поддерживает yt-dlp:

```bash
vklecture --cookies-from-browser "chromium:$HOME/.config/chromium/Default" \
  "https://vkvideo.ru/video..."
```

Для Helium путь к профилю уточни на странице `chrome://version`; не подставляй
путь Chromium автоматически. Импорт/расшифровка cookies зависит от браузера
и его хранилища ключей. Альтернатива — уже имеющийся Netscape-файл cookies:

```bash
vklecture --cookies "$HOME/Downloads/vk-cookies.txt" "https://vkvideo.ru/video..."
```

Файл cookies содержит доступ к сессии аккаунта; не отправляй его другим людям.
Утилита передаёт его локальному yt-dlp и не включает содержимое в результаты.

Если сообщение говорит об ошибке экстрактора VK, обнови yt-dlp через
`sudo pacman -Syu`. Можно проверить его отдельно:

```bash
yt-dlp --ignore-config --no-playlist -F "https://vkvideo.ru/video..."
```

Изменения на сайте VK или недоступность конкретного видео могут мешать загрузке.
Если файл уже скачан, локальное распознавание от доступности VK не зависит.

При проверке указанной в инструкции лекции из среды подготовки проекта
yt-dlp 2026.08.19 получил `HTTP Error 405: Not Allowed` при запросе метаданных.
Поэтому загрузка **именно этой лекции** здесь не подтверждена. Это не доказывает,
что ошибка повторится в твоей сети. Если повторится, проверь доступ в браузере,
актуальность yt-dlp и cookies; либо используй скачанный видео/аудиофайл.

## 12. Ошибки и восстановление

| Сообщение | Действие |
|---|---|
| `command not found: vklecture` | Добавь `~/.local/bin` в PATH или используй полный путь |
| Нет `whisper-cli` | Повтори `bash install.sh medium` без sudo |
| Нет модели | Скачай её через `scripts/download-model.sh` или выбери установленную |
| Скачивание модели оборвалось | Повтори команду; `.part` будет докачан |
| `failed to load model` | Проверь путь; для повреждённой модели переименуй её файл и скачай заново |
| Процесс убит / не хватает памяти | Выбери small, закрой тяжёлые программы или разбей лекцию на части |
| FFmpeg не находит аудиопоток | Проверь, что исходный файл содержит звук |
| VK выдаёт ошибку доступа | Проверь доступ в браузере и передай cookies |

При ошибке программа не пишет «Готово», возвращает ненулевой код и оставляет
рабочие файлы. Можно повторно распознать `audio/lecture.wav` из напечатанного
каталога как локальный файл; скачивать видео заново не потребуется.

## 13. Ручная сборка своей C++-программы

После установки зависимостей:

```bash
cd ~/Applications/vklecture-cpp
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel 2
install -m 755 build/vklecture ~/.local/bin/vklecture
```

Или напрямую компилятором:

```bash
g++ -std=c++23 -O2 -Wall -Wextra -Wpedantic src/main.cpp -o vklecture
./vklecture --help
```

Эти команды собирают только управляющую утилиту. whisper-cli и модели
должны быть уже установлены через `install.sh`.

Пути установки по умолчанию:

| Путь | Содержимое |
|---|---|
| `~/.local/bin/vklecture` | Команда |
| `~/.local/share/vklecture/whisper.cpp` | Исходники и сборка движка |
| `~/.local/share/vklecture/models` | Модели |
| `~/.local/share/vklecture/default-model` | Выбранная модель по умолчанию |

Нестандартный каталог можно выбрать через `VKLECTURE_HOME`. Его значение
должно совпадать при установке, загрузке дополнительных моделей и запуске:

```bash
export VKLECTURE_HOME="$HOME/Applications/vklecture-data"
bash install.sh medium
vklecture "Лекция 1.mp4"
```

Сборка оптимизирована под CPU компьютера, где выполнялась установка.
На другом компьютере лучше снова выполнить install.sh.

## Проверка проекта

Для разработчика: `python tests/test_pipeline.py` выполняет интеграционные
проверки с настоящим FFmpeg и заменами yt-dlp/whisper-cli. Проверяет передачу
URL и аргументов без shell, русские пути с пробелами, ошибки и сохранность
исходника. Python нужен только для этих тестов, не для C++-утилиты.

Результаты проверки в среде подготовки приведены в `VALIDATION.md`.
